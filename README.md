# cils_robot_news

Daily drone and robotics industry news, collected each morning (Taipei time).

```
YYYY-MM-DD/
  upload.json   {"date", "headline_groups", "html"}  (single-line JSON, UTF-8)
  news.html     the same page as in upload.json, for preview
```

Raw URL of a day's file:

```
https://raw.githubusercontent.com/Lien6410/cils_robot_news/main/YYYY-MM-DD/upload.json
```

Summaries are rewritten from the cited sources; figures and quotes follow the originals.
